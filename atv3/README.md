# Orquestrador de Dados

Aplicativo desenvolvido em Flutter para a Unidade Curricular de Desenvolvimento de Sistemas Móveis (DSM) – UniSENAI.

## Sobre

Protótipo de monitoramento de ordens de serviço de uma frota de veículos elétricos, desenvolvido para demonstrar navegação, gerenciamento de estado e transferência de dados entre telas.

## Funcionalidades

* Visualização de ordens de serviço.
* Filtros por status, veículo e prioridade.
* Navegação com `Navigator.push()` e `await`.
* Transferência do objeto `FiltroModel`.
* Retorno de dados com `Navigator.pop()`.
* Atualização da interface com `setState()`.

## Tecnologias

* Flutter
* Dart
* Visual Studio Code
